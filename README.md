# Kryon

This repository contains both the Kryon application and its interactive landing-page prototype.

## Repository layout

| Directory | Contents |
| --- | --- |
| [`project/`](project/README.md) | The Python Kryon application, installation scripts, source code, and tests. |
| [`landing-page/`](landing-page/README.md) | A dependency-free static prototype of the Kryon security-operations interface. |

## Start here

- For the application, follow the installation and usage instructions in [`project/README.md`](project/README.md).
- For the UI prototype, open [`landing-page/index.html`](landing-page/index.html) in a modern browser. It has no build step or package dependencies.

## Status

The Python project is in alpha. The landing page is an interactive front-end prototype and does not perform security testing or connect to the Python application.
